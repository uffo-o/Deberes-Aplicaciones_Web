Guías rápidas

Cómo empezar

Para preparar un equipo puedes seguir estos pasos:

  1. Revisar las estadísticas del personaje.
  2. Comprobar su atributo y alcance.
  3. Elegir un compañero adecuado.
  4. Mejorar y despertar las unidades necesarias.

Conceptos básicos

Chakra
Recurso utilizado para realizar determinadas técnicas.
Buddy
Personaje de apoyo que acompaña a una unidad principal.
Awakening
Proceso de mejora que permite potenciar determinadas unidades.
